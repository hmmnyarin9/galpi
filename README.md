# 갈피 · Galpi

**잠깐 적고, 이어가세요.** Windows에서 한 줄 기록 습관을 돕는 로컬 우선 앱입니다.

## 구성

- 앱: Rust + Tauri 2, TypeScript + Vite. 외부 UI 프레임워크 없이 구현.
- 저장소: Rust에서 접근하는 SQLite. 기록은 서버로 전송하지 않음.
- 배포 페이지: `site/dist/`의 빌드 없는 정적 HTML/CSS. 앱과 독립적으로 배포.
- 대상: Windows x64. NSIS 설치 파일. 현재 개발 미리보기이며 코드 서명 없음.

## 개발

Node.js 22.12 이상(또는 20.19 이상), Rust stable 1.90 이상, MSVC C++ 빌드 도구와 Windows SDK, WebView2가 필요합니다.

```powershell
npm install
npm run tauri dev
```

Rust를 PATH 변경 없이 설치했다면 먼저 현재 터미널에 경로를 추가합니다.

```powershell
$env:PATH = "$env:USERPROFILE\.cargo\bin;$env:PATH"
```

브라우저 UI 미리보기: `npm run dev`. 브라우저에서는 별도 localStorage에 저장하고 트레이·전역 단축키·Windows 알림은 작동하지 않습니다.

```powershell
npm run build
npm test
cargo test --manifest-path src-tauri/Cargo.toml
npm run tauri build
```

생성 위치: `src-tauri/target/release/bundle/nsis/`.

## 현재 동작

- 날짜 표시 없이 입력창과 기록 목록·기간 필터(오늘·7일·전체)·검색 표시. 톱니 아이콘으로 설정 열기.
- Windows 기본 제목표시줄 없음. 상단 빈 공간을 드래그해 이동하고, 오른쪽 버튼으로 최소화·트레이로 숨기기.
- 팝업 전환 시 입력창 좌상단의 화면 위치로 창을 이동하고, 복원 시 현재 팝업 위치에서 입력창 오프셋을 역산. 디스플레이 배율과 기존 스크롤을 반영해 입력창의 화면상 위치를 유지.
- 팝업에 마우스를 올리면 블러 영역을 드래그해 창 이동 가능. 중앙 복원 버튼은 별도로 클릭해 일반 모드로 복귀.
- 트레이 우클릭 메뉴는 ‘열기 · 설정 · 종료’. ‘열기’는 현재 일반/팝업 모드를 유지하며, ‘설정’은 팝업을 해제하고 일반 창에서 설정을 표시.
- 설정에서 ‘Windows 시작 시 실행’과 하위 옵션 ‘최소화로 시작’ 제공. 기본 꺼짐. 자동 실행을 켜야 하위 옵션을 선택할 수 있으며, 로그인 시 자동 실행되는 경우에만 창 없이 트레이에서 시작. 직접 실행하면 창 표시. 브라우저에서는 두 옵션 비활성화.
- 일반 창 720×720 고정. 최소화 옆의 팝업 버튼을 누르면 입력 필드·다음 할 일·저장 버튼을 포함한 입력창 전체의 실제 너비·높이에 맞게 창을 축소. 팝업에서는 설정·최소화·닫기 버튼과 기록 목록만 숨기고, 저장 버튼과 `Ctrl+Enter` 모두 사용 가능. 다음 할 일을 펼치거나 접으면 창 높이도 맞춰 변경. 마우스를 올리거나 복원 버튼에 키보드로 접근하면 팝업 전체를 블러 처리하고 중앙에 복원 버튼 표시. 다시 누르면 이전 창 크기와 스크롤 위치로 복귀. 작성 중 내용·다음 할 일·검색·기간 필터는 모드 전환 시 유지. 텍스트 입력 영역의 포커스링 제거.
- Windows Acrylic 배경과 반투명 입력창. 브라우저 미리보기는 불투명 배경이며, Windows의 효과 지원 및 투명 효과 설정에 따라 표현이 달라질 수 있음.
- 설정·수정·삭제 확인 창에 짧은 페이드·이동 전환과 배경 페이드 적용. 운영체제의 동작 줄이기 설정에서는 전환 생략.
- 한 줄 또는 여러 줄 기록, 선택적인 ‘다음에 할 일’, 작성 중 내용 임시 보관.
- 기록별 ‘수정’ 버튼으로 본문과 다음에 할 일 편집. 처음 작성한 날짜를 유지하고, 저장 전 취소 시 변경 버리기를 확인.
- 편집창에서도 `Ctrl+Enter`로 저장. 새 기록의 임시 보관 내용은 편집과 별도로 유지.
- 오늘·모든 기록·지난 7일, 본문과 다음 행동 검색, 삭제 전 확인.
- 검색어를 입력하면 선택한 기간 탭과 관계없이 전체 기록을 검색하며, 검색어를 지우면 기존 탭으로 복귀. 결과에 연도를 포함한 날짜와 일치 단어를 표시하고, 긴 기록은 일치 문장 주변을 미리 보여주며 ‘전체 보기’로 확장 가능.
- `Ctrl+F`로 기록 검색에 이동(팝업에서는 일반 모드로 복원), 검색창에서 `Esc`로 검색어 지우기. 달력 버튼에서 시작일·종료일을 선택해 날짜 범위를 제한하며, 검색어와 함께 사용 가능. 양 끝 날짜를 포함하고, 한쪽 날짜만 지정하거나 기간을 초기화할 수 있음.
- 빠른 기록 단축키 기본값 `Ctrl+Alt+G`. 설정의 입력칸에서 Ctrl/Alt와 영문·숫자·F키 조합을 눌러 변경하고 저장. 기본값 복원 가능. 충돌 시 기존 단축키와 설정 유지. 다음 실행 시에도 적용.
- 창 닫기와 Escape: 트레이로 숨김. 트레이 오른쪽 메뉴로 완전히 종료.
- 단일 인스턴스: 재실행하면 기존 창 표시.
- 알림: 기본 꺼짐. 앱이 실행 중이고 설정 시각이 되면 하루 한 번 발송 시도. 중복 발송 방지 상태는 SQLite에 저장.
- JSON 전체 내보내기. 파일 선택은 네이티브 저장 대화상자로 처리.

기록과 설정은 `%LOCALAPPDATA%\galpi\galpi.sqlite3` 및 관련 WAL/SHM 파일에 저장됩니다. 새 위치에 DB가 없으면 첫 실행 시 기존 `%APPDATA%\kr.galpi.desktop\galpi.sqlite3`에서 SQLite 백업으로 이전하며, WAL의 최신 기록과 설정도 포함합니다. 기존 파일은 보존하고, 새 위치에 DB가 있으면 덮어쓰지 않습니다. 이전에 실패하면 빈 DB로 시작하지 않고 오류를 보고합니다. 작성 중인 임시 기록은 기존 앱 WebView의 localStorage에 유지됩니다. 앱 설정에서 실제 DB 폴더를 확인할 수 있습니다. 데이터는 암호화하지 않으며 Windows 사용자 계정의 파일 접근 권한에 의존합니다.

## 아직 포함하지 않은 기능

- 동기화, JSON 가져오기, 자동 업데이트, 코드 서명.
- 잠들어 있거나 종료된 PC에서의 알림, 놓친 알림의 지연 재발송.
- 전용 소형 빠른 기록 창(현재 단축키는 메인 창의 입력창을 엽니다).

## 다운로드 페이지

`site/dist`를 정적 호스팅에 배포할 수 있습니다. 런타임 서버나 DB가 필요하지 않습니다.

`node scripts/prepare-download.mjs`는 빌드한 NSIS 설치 파일을 `site/dist/downloads/`에 복사하고 SHA-256 파일을 생성합니다. 실제 빌드가 없으면 실패하며 다운로드 버튼에 가짜 파일을 연결하지 않습니다.

`galpi.kr` DNS 및 공개 도메인 연결은 별도 설정이 필요합니다. 현재 Sites 프로젝트 정보는 `site/.openai/hosting.json`에 있습니다.
